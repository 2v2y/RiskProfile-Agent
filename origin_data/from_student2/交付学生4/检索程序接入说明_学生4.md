## 三、standard字段格式转换（重要）

### 问题

违章数据（学生1交付的violation_clean.csv）中的standard字段格式与知识库中的格式不同，必须转换后才能检索。

### 两种格式对比

| 来源 | 格式 | 举例 |
|------|------|------|
| 违章数据（DOL API） | 无小数点 + 段落代码 | `19100120 Q01` |
| 知识库（OSHA法规网站） | 带小数点 | `1910.120` |

### 转换规则

```
输入: 19100120 Q01
步骤1: 取空格前的部分 → 19100120
步骤2: 前4位是Part → 1910
步骤3: 后4位是Section → 0120
步骤4: Section转整数去前导零 → 120
步骤5: 拼接 → 1910.120
```

### Python转换函数

```python
def convert_standard(raw):
    """
    将DOL API格式转换为知识库格式
    '19100120 Q01' → '1910.120'
    '19260020 B02' → '1926.20'
    """
    if not raw:
        return None
    raw = raw.strip()
    parts = raw.split()
    if not parts:
        return None
    code = parts[0]
    if not code.isdigit() or len(code) < 7:
        return None
    part = code[:4]        # 1910 或 1926
    section_str = code[4:]  # 0120
    try:
        section_num = int(section_str)
    except ValueError:
        return None
    if part not in ('1910', '1926'):
        return None
    return f"{part}.{section_num}"
```

### 转换示例

| 违章数据格式 | 知识库格式 | 对应法规 |
|-------------|-----------|---------|
| 19100120 Q01 | 1910.120 | 危险废弃物操作 |
| 19260020 B02 | 1926.20 | 通用安全健康条款 |
| 19260021 B02 | 1926.21 | 安全培训 |
| 19260150 E01 | 1926.150 | 消防保护 |
| 19101325 | 1910.1325 | （超出知识库范围，检索不会命中） |

### 注意事项

1. 转换后的标准编号不一定会全部命中知识库——知识库只收录了电力相关重点标准（93条）
2. 转换后未命中的standard，检索程序应返回"未找到相关法规"
3. 段落代码（Q01、B02等）不参与检索，只用于违章记录的子条款定位

## 四、检索流程

```
违章记录 standard="19100120 Q01"
    ↓ 格式转换
查询关键词="1910.120"
    ↓ 向量检索(TF-IDF)
在regulation_chunks.jsonl的4656条片段中搜索
    ↓ 返回得分最高的3条
chunk_001234  1910.120  §1910.120 General requirements...
chunk_001235  1910.120  §1910.120(a) Scope, application...
chunk_001236  1910.120  §1910.120(b) Definitions...
```
