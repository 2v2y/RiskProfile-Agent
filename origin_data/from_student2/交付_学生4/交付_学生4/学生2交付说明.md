## 二、检索接口调用方式

```python
from rag_retriever import RAGRetriever

retriever = RAGRetriever()
results = retriever.search("1910.132", k=3)

# 返回格式：list[dict]
# 每条结果含：chunk_id, standard, section, text, score
```

- 标准编号查询（如"1910.132"）：精确过滤 + section匹配优先 + BGE语义排序
- 自然语言查询：纯BGE语义检索
- 推荐参数：`k=3`

## 三、检索验证结果

验证集：93条查询（标准编号类型）
评估指标：Recall@k, Precision@k, MRR, NDCG@10

| 方法 | k | Recall | MRR | NDCG@10 |
|------|---|--------|-----|---------|
| 混合检索（推荐） | 3 | **1.0000** | **0.8530** | **0.8914** |
| 混合检索 | 10 | 1.0000 | 0.8530 | 0.8914 |
| 纯BGE向量 | 10 | 0.0000 | 0.0000 | 0.0000 |
| 关键词(TF-IDF) | 10 | 0.6559 | 0.2290 | 0.3296 |

结论：混合检索（精确过滤+section匹配+BGE排序）效果最优，Recall@3=100%。

## 四、R1-R9风险分类映射

使用 `knowledge/standard_to_r1r9_mapping.csv`（学生1制作，最终版）。

**注意编号格式差异**：
- 映射表用的是DOL格式：`19100269`、`19261050`
- 知识库chunks用的是标准格式：`1910.269`、`1926.1050`
- 转换方法：去掉前4位前缀（1910/1926），剩余部分去前导零，加回点号
  - `19100269` → 去前缀`1910` → `0269` → 去前导零 → `269` → `1910.269`
  - `19261050` → 去前缀`1926` → `1050` → 无前导零 → `1926.1050`

映射表列名：`standard_code, standard_normalized, r_category, r_category_name, basis`

R分类列表：R1-R9（无R6）


## 七、向量库与片段的对应关系

```
chunk_ids.json       → chunk_id列表，顺序对应FAISS索引
faiss_index.bin      → FAISS索引（4656个向量，384维）
embeddings.npy       → 原始向量矩阵（4656×384）
regulation_chunks.jsonl → 4656条片段正文
```

通过 `chunk_ids.json` 的索引位置可以找到对应的 `chunk_id`，再用 `chunk_id` 在 `regulation_chunks.jsonl` 中查找完整内容。`rag_retriever.py` 已封装了这整套逻辑。
