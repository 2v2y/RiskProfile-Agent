## 二、关于P1-2：risk_percentile 口径书面确认 ✅ 已确认

### 确认结论

**交付口径 = 0—100 百分位，程序按 /100 转为 0—1。**

### 详细说明

| 项目 | 说明 |
|------|------|
| 交付值域 | 0.4 — 100.0（百分位口径） |
| Schema定义 | 0 — 1（比例口径） |
| 转换方式 | `schema_value = delivered_value / 100` |
| 唯一值数量 | 314个不同值 |
| 最小值 | 0.4（即第0.4百分位） |
| 最大值 | 100.0（即第100百分位） |

### 转换逻辑

```python
# 交付值（0-100百分位）
risk_percentile_delivered = 40.0  # 表示排在同季度前40%

# Schema值（0-1比例）
risk_percentile_schema = risk_percentile_delivered / 100  # = 0.40
```

### 历史原因

该字段在生成时使用了 `rank() / count() * 100` 计算百分位排名，结果是0-100范围。Schema和白名单中定义为0-1是因为JSON Schema惯例。两者数学等价，程序在使用时做 `/100` 转换即可。

> **无数据质量问题**——值域连续、无缺失、无异常值。口径差异是编码惯例问题，不是数据错误。
