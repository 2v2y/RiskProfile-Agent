# 模型评价指标说明

## 1. 要回答的问题

在每个历史测试季度中，先事后确定当季实际发生且符合计划性检查规则的候选代理实体，再使用季度开始日前的历史画像排序。比较加入动态画像后，候选检查中最终签发 citation 的 episode 是否更靠前。

估计对象为：

> 在已观察到的计划性检查 episode 条件下，规定观察窗内签发 citation 的相对排序信号。

不估计未检查单位、所有企业的真实违章、事故、伤亡或现实检查干预收益。

## 2. 时间切分预置协议

| 集合 | 时间 | 用途 |
|---|---|---|
| Train | 2015Q1—2021Q4 | 拟合参数和预处理 |
| Validation | 2022Q1—2023Q1 | 核对固定方法的表现并完成冻结，不在本版本临时调参 |
| Embargo | 2023Q2—2023Q4 | 不用于建模，降低标签跨界风险 |
| 模型冻结截点 | 2024-01-01 | 此日前冻结特征、模型和评价 |
| Test | 2024Q1—2025Q4 | 最终一次主评价 |

若正式签发时滞或数据覆盖证明该方案不满足成熟要求，可在 Test 标签开封前整体调整，并记录原因和新版本。已查看 Test 标签后不得改主切分以追求更好结果。

## 3. 固定方法

| 编号 | 方法 | 特征 | 地位 |
|---|---|---|---|
| R0 | Beta-Binomial平滑历史率 | 单一平滑历史率 | 最简单参考 |
| M1 | Logistic Regression | Context + Static | 静态画像主基线 |
| M2 | 同一 Logistic Regression | Context + Static + Dynamic | 主检验方法 |

M1与M2必须使用相同的样本、编码、补值、缩放、正则化设置和随机种子。所有预处理在 Train 拟合；当前版本的逻辑回归参数、半衰期和特征组已经在 `config.yaml` 预先固定，Validation只用于核对表现和冻结整套方法，不从临时候选中挑最好设置；Test只做最终预测。

## 4. 每季度排序

对季度 `q` 的 `n_q` 个候选样本按模型分数从高到低排序。`sample_id` 升序只用于固定 Top-20% 名额边界的并列顺序；AP 按标准分数阈值处理同分组，同分组内部的匿名编号不会改变 AP。

前20%的名额数：

\[
K_q=\lceil 0.20\times n_q\rceil
\]

即使季度样本很少，`K_q` 至少为1。每个季度独立计算名额，不把所有季度混在一起取前20%。

## 5. 主指标：季度AP

Average Precision（AP）综合衡量阳性样本在整个排序中的位置。对每个测试季度单独计算，采用标准 precision-recall 阶梯积分；分数相同的样本作为同一阈值组处理。

主汇总为按候选数加权的季度AP：

\[
AP_{weighted}=\frac{\sum_q n_q AP_q}{\sum_q n_q}
\]

无阳性的季度无法定义AP，应记为NA并报告季度数量；主汇总只对可定义季度计算，同时在正文说明排除规则。宏平均季度AP作为次要指标。

## 6. 应用指标：Recall@20%

每季度前 `K_q` 个候选中命中的阳性数为 `hits_q`，该季度阳性总数为 `P_q`：

\[
Recall@20\%_q=\frac{hits_q}{P_q}
\]

主汇总采用所有可定义季度的命中数之和除以阳性数之和：

\[
Recall@20\%=\frac{\sum_q hits_q}{\sum_q P_q}
\]

无阳性季度记为NA，不填0。

## 7. 次要指标

### Precision@20%

\[
Precision@20\%_q=\frac{hits_q}{K_q}
\]

### Lift@20%

\[
Lift@20\%_q=\frac{Precision@20\%_q}{P_q/n_q}
\]

当季度无阳性时 Lift 不定义。次要指标用于解释，不改变主判断标准。

## 8. 配对Bootstrap置信区间

主统计使用至少2000次代理实体聚类配对Bootstrap：

1. 以 `entity_proxy_id` 为聚类单位有放回抽样；
2. 被抽中的实体携带其全部相关测试季度样本；
3. 同一重复中，M1和M2使用完全相同的重采样实体；
4. 重复实体生成唯一复本编号，避免并列排序键冲突；
5. 每次重新计算季度指标和M2−M1差值；
6. 使用差值分布的2.5%和97.5%分位数形成配对95%置信区间；
7. 记录随机种子、有效重复次数和失败原因。

若测试代理实体数量过少、多个季度无阳性或区间不稳定，应如实报告，不通过改变抽样单位获得更窄区间。

## 9. 主判断标准

预置标准：

- C1：M2−M1 加权季度AP差值的配对95%置信区间下界大于0；
- C2：M2−M1 Recall@20%差值的配对95%置信区间下界大于0，且8个测试季度中至少5个季度方向为正。

结果写法：

| 结果 | 规范解释 |
|---|---|
| C1、C2均满足 | 当前协议下支持动态画像具有稳定增量排序价值 |
| 点估计为正但区间跨0或季度不稳定 | 有改善迹象，但证据不足以支持稳定增益 |
| 差值为0或负 | 当前动态定义未带来增量价值 |

不得仅凭某一个季度或某一个次要指标改写主结论。

## 10. Test隔离与运行规则

1. Test 特征文件不包含标签；
2. Test 标签单独保存并记录 SHA-256；
3. 在 Test 开封前冻结数据、特征、模型、指标、随机种子和代码版本；
4. 先生成不带答案的 Test 预测文件并记录校验值；
5. 在监督下按 `sample_id` 一对一合并答案；
6. 合并必须检查无缺失、无多余、无重复；
7. 开封后不以结果为依据改动主方案；
8. 必要勘误保留原结果，并单独说明问题、修正和影响。

运行信息写入 `实验运行.csv`，每个输出数字写入 `结果核对.csv`。

## 11. 当前正式范围之外的扩展分析

本材料包当前只实现并冻结 `insp_type=H`、固定180天观察窗、固定365天半衰期和 R0/M1/M2 比较，不自动生成 I/K、删除标记替代标签、树模型、替代半衰期或其他扩展结果。论文不得把这些项目写成已经完成。

若以后确需增加扩展分析，必须在正式 Test 首次开封前另建程序版本、配置、输出目录和可复现记录，并由 Validation 冻结。扩展结果须与主分析分表展示，且不能选择最有利结果替代主结果。
