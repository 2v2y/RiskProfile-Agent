# 风险分类规则

## 1. 分类目的与边界

风险分类用于把公开 Violation 主表中的 `standard` 整理成可解释的业务类别，支持类别分布、案例解释和国内字段映射。公开主表没有通用 citation 描述文本，因此正式主分类不得等待或假定存在 `risk_text`。外部公开文字仅在来源可核验时作为补充材料。分类不替代 OSHA 或中国法规原文，不用于自动判定单位违法，也不改变主标签。

主标签始终是：符合候选规则的检查 episode 在规定观察窗内是否签发至少一条直接关联 citation。风险类别是描述性或次要画像字段。

美国 OSHA 条款与中国电力安全规程不存在默认的一一等价关系。任何国内映射都必须写成“管理字段对应建议”，不能写成法规等价转换。

## 2. 分类版本

每次正式分类登记：

- 分类规则版本；
- citation 数据快照；
- 使用的标准代码说明版本；
- 国内规程名称、版本和章节；
- 标注者、裁定人和电力安全复核人；
- 启用日期、停用日期和变更原因。

分类规则更新时保留旧标注，不覆盖历史。新旧版本的差异和受影响记录数写入 `数据问题.csv`。

## 3. 九个主类

| 代码 | 类别 | 判定重点 | 常见情形 | 与相邻类别的边界 |
|---|---|---|---|---|
| R1 | 电气危险与带电防护 | 触电、电弧、裸露带电部分、接近带电体、断电确认 | 带电部位未隔离；安全距离不足；临时用电防护不当 | 个人装备为核心时可归R2；上锁挂牌为核心时归R3 |
| R2 | 个人防护装备 | 人员应穿戴或使用的个体防护装备缺失、选择错误或使用不当 | 安全帽、防护眼镜、绝缘手套、防护服、听力防护 | 集体防护归R4/R7/R8；机械防护罩归R6 |
| R3 | 能量隔离与上锁挂牌 | 检修或进入危险区域前未可靠隔离危险能量 | 未上锁挂牌；隔离点不完整；未验证无能量 | 一般裸露带电危险归R1；机械防护罩归R6 |
| R4 | 高处作业与坠落防护 | 梯子、脚手架、屋面、杆塔、平台等位置的人员坠落风险 | 护栏缺失；锚点不合格；梯子使用不当 | 物体打击归R8；个人防坠装备可列R2副类 |
| R5 | 作业许可、培训与程序执行 | 许可、培训、资质、告知、程序或监护不足 | 未培训；无许可；程序未执行；缺少监护 | 明确实体危险优先作主类，管理缺陷可作副类 |
| R6 | 机械设备与工器具安全 | 运动部件、起重设备、车辆、工具的使用和防护 | 防护罩缺失；工具损坏；起重操作不当 | 电气工具触电主导归R1；车辆与人员隔离主导可归R8 |
| R7 | 受限空间、消防与危险环境 | 有限空间、缺氧、有毒气体、火灾爆炸、动火和危险物质环境 | 未检测气体；动火控制不足；消防通道阻塞 | 高处或电气为核心时分别归R4/R1 |
| R8 | 现场通道、物体打击与综合防护 | 通道、堆放、孔洞、落物、车辆人员交叉等布置问题 | 通道堵塞；堆放不稳；吊物下站人；孔洞未覆盖 | 明确人员坠落归R4；运动部件归R6；消防通道归R7 |
| R9 | Other/Unmapped | 当前 `standard` 映射无法可靠归入R1—R8，或标准值缺失、格式异常 | 未建立映射；非目标标准体系；需专业复核 | 不为提高覆盖率而强行归类 |

## 4. 主类与副类

每个规范化 `standard` 只建立一个主类映射，可填写零至两个副类。

- 主类回答“该标准主要对应哪类危险或管理要求”；
- 副类仅在官方标准说明明确涉及另一类问题时填写；
- 主类与副类不得相同；
- 两个副类按官方标准说明中的主次排序；
- 无法从 `standard` 和可核验的官方标准说明可靠归类时，归R9并登记原因，不补造现场事实。

具体 `standard→R1—R9` 映射必须形成独立、版本化规则表，记录匿名 `classification_record_id`、标准原值、规范化值、`viol_type`、官方标准说明入口、主类、副类、依据和复核状态。本材料不预填未经逐条核验的标准代码映射。

## 5. 标注流程

1. 使用 `结果/01_数据审计/风险分类输入_最小字段.csv`；一行代表一个 `standard×viol_type` 组合，并以 `classification_record_id` 标识；
2. 分类输入只保留分类所需代码和汇总数量，不向分类人员提供 `activity_nr`、`citation_id`、日期、单位、split 或 Test 标签；
3. 规范化 `standard`，但原始值不得覆盖；
4. 初分人员与复核人员分别在 `风险分类_初分.csv` 和 `风险分类_复核.csv` 中填写主类、0—2个副类、命中规则编号、信心、不确定状态与判定依据；两人完成前不得查看对方文件；
5. 两份文件分别锁定后计算SHA-256，把校验值和锁定时间写入 `文件交接.csv`；只有两份锁定记录都完整时，才按 `classification_record_id` 比较并合并为 `风险分类.csv`；
6. 类别一致的记录进入一致集合，其他记录写入 `分类分歧.csv`；
7. 裁定人依据代码、官方标准说明、分类规则和专业意见形成最终类别；
8. 最终表同时保留初分、复核和裁定结果，不删除分歧痕迹；
9. 分类规则因高频分歧而修改时，形成新版本并重新处理受影响范围。

独立标注保留在两张独立表，合并和裁定内容写入 `风险分类.csv`，不得在原始 citation 表上直接覆盖。

## 6. 信心等级

| 等级 | 含义 | 处理方式 |
|---|---|---|
| 高 | 官方标准说明明确且分类边界清楚 | 正常进入一致性统计 |
| 中 | 标准主题可判断，但涉及相邻类别 | 重点抽查 |
| 低 | 标准值异常、说明不足或需专业知识 | 必须进入裁定队列 |

低信心记录即使A、B主类相同，也要抽样复核，避免一致地误判。

## 7. 质量指标

每一批次至少报告：

- 双人共同标注条数；
- 主类完全一致条数与比例；
- Cohen's kappa 或经批准的另一项一致性指标；
- 各主类数量和占比；
- R9数量、占比及主要原因；
- `standard`非空覆盖率、成功映射覆盖率和未映射率；
- 低信心数量；
- 最常见分歧类别对；
- 裁定后变更条数；
- 因规则修订而重新标注的条数。

一致率不能单独作为唯一质量证据。类别严重不平衡时同时查看混淆表和各类样本数。

## 8. 与主模型的关系

当前 R0、M1、M2 不把人工风险类别作为模型特征。分类结果只用于：

- 描述不同 `standard×viol_type` 组合的语义构成；
- 形成可人工核对的案例说明；
- 设计国内电力安全数据的建议字段。

不得把汇总数量展开成具体检查记录，不得据此推导 Test 标签，也不得把“类别严重”转化为未经验证的绝对风险权重。若以后希望把风险类别作为画像特征，必须另建研究版本、完成逐记录时间可用性连接，并在 Test 开封前重新冻结；不属于本执行包。

## 9. 国内字段映射

| 类别 | 可讨论的国内管理字段 | 使用限制 |
|---|---|---|
| R1 | 电压等级、停电范围、安全距离、验电接地 | 仅作字段建议，不称条款等价 |
| R2 | 安全帽、绝缘手套、防护服等穿戴检查 | 需说明字段是否真实存在 |
| R3 | 工作票安全措施、隔离点、挂牌上锁、许可状态 | 需由专业人员审核术语 |
| R4 | 作业高度、安全带、锚点、杆塔作业 | 不从OSHA数据推断国内发生率 |
| R5 | 人员资质、培训、工作票、监护人 | 不自动用于人员定责 |
| R6 | 工器具试验状态、起重设备、车辆 | 不替代设备检验 |
| R7 | 有限空间、动火、气体检测、消防措施 | 需匹配适用规程 |
| R8 | 通道、围栏、孔洞、吊装区域、现场布置 | 只用于辅助复核 |
| R9 | 人工复核队列 | 不自动分配严重性 |

## 10. 批次验收条件

- [ ] 两名标注者确实独立完成；
- [ ] 初分表与复核表在比较前已分别锁定，且锁定时间和SHA-256已登记；
- [ ] `classification_record_id` 唯一，`standard`、`viol_type` 和汇总数量完整保留；
- [ ] 普通分类表不含 `activity_nr`、`citation_id`、日期、单位、split 或 Test 标签；
- [ ] 所有低信心与主类分歧记录均已进入裁定；
- [ ] 分类规则版本、人员和日期完整；
- [ ] 质量指标已生成且可复算；
- [ ] `standard`有效值覆盖率、映射覆盖率和Other/Unmapped比例已报告；
- [ ] 分类结果未作为当前主模型特征；
- [ ] 专业复核意见已归档；
- [ ] 论文没有把风险分类写成法规等价或自动定责。
