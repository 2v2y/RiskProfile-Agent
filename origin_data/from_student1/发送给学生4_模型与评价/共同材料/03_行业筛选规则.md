# 行业筛选规则

## 1. 研究范围名称

统一使用“电力及电气相关行业”。不得把筛选结果统称为“四川电网企业”“纯电网企业”“供电公司样本”或“中国电力企业”。

原因：`237130` 同时覆盖电力与通信线路及相关结构施工；`238210` 覆盖范围较广的电气承包和布线安装活动。公开 OSHA 样本也不等同于四川电网的机构范围。

## 2. NAICS 版本

每个正式快照登记：

- OSHA 记录适用的 NAICS 版本或年份；
- 数据中实际出现的代码长度和格式；
- Census 官方定义页面的访问日期；
- 跨版本代码是否发生变化；
- 版本变化对纳入范围的影响。

行业定义以对应年份的美国 Census 官方 NAICS 资料为准。不同版本不得在不说明的情况下合并。

## 3. 代码规范化

1. 原始值先按字符串读取，保留原始列；
2. 去除两端空格，不改变中间字符；
3. Excel 产生的小数、科学计数、前导零异常进入 `数据问题.csv`；
4. 只有能够无歧义恢复为合法 NAICS 代码时，才生成规范化字段；
5. 空值和不可解释值不进入 G1—G4，并保留排除原因；
6. 原始值、规范化值和转换规则同时保存。

## 4. 四个互斥行业组

| 组别 | 精确规则 | 用于论文的名称 | 必须说明的边界 |
|---|---|---|---|
| G1 | `naics_code == "221122"` | 电力配电 | 属于2211子类，必须先于G2判断 |
| G2 | `naics_code` 以 `2211` 开头且不等于 `221122` | 其他发电、输电和配电 | 不得再次包含G1 |
| G3 | `naics_code == "237130"` | 电力和通信线路及相关结构施工 | 包含通信线路、通信塔等活动 |
| G4 | `naics_code == "238210"` | 电气承包和其他布线安装 | 可能包含建筑电气、报警和通信布线 |

判断顺序固定为：

```text
恰好等于221122              → G1
否则，以2211开头             → G2
否则，恰好等于237130         → G3
否则，恰好等于238210         → G4
否则                         → 不纳入行业范围
```

## 5. 互斥性检查

对每个快照完成以下自动检查：

1. 每条记录最多属于一个组；
2. `G1 + G2 + G3 + G4` 的不同 `activity_nr` 数等于行业筛选后的不同检查总数；
3. `221122` 不得出现在 G2；
4. 不符合规则的 221、237、238 相邻代码不得被模糊纳入；
5. NAICS 缺失数和格式异常数单独报告；
6. 按年、季度、州和行业组报告不同检查数；
7. 若一条 `activity_nr` 出现矛盾 NAICS，先登记问题，不以任意一行覆盖。

结果写入 `字段检查.csv` 和 `样本筛选.csv`。

## 6. 与 Inspection—Citation 连接的顺序

主表先在 Inspection 层面完成行业筛选，再使用 `activity_nr` 连接 citation。

- 采用保留无 citation 检查的左连接；
- 一次检查可对应多条 citation；
- 连接前后不同 `activity_nr` 总数应一致，除非有已登记的排除规则；
- 检查级标签先对 citation 汇总，再回连到检查，不能把 citation 明细行数当作检查次数；
- Violation 中无法连接到目标行业 Inspection 的记录另存审计表，不反向扩充行业范围。

## 7. 最低报告表

正式报告至少包含以下行：

| 报告项 | 统计口径 |
|---|---|
| 原始不同检查数 | 未做行业筛选的唯一 `activity_nr` |
| NAICS 缺失检查数 | 规范化后仍为空 |
| NAICS 格式异常检查数 | 无法无歧义解释 |
| G1检查数 | 唯一 `activity_nr` |
| G2检查数 | 唯一 `activity_nr` |
| G3检查数 | 唯一 `activity_nr` |
| G4检查数 | 唯一 `activity_nr` |
| 行业筛选后检查总数 | G1—G4并集 |
| 多组重叠检查数 | 正常应为0 |
| 行业筛选后有citation检查数 | 检查级计数 |
| 行业筛选后无citation检查数 | 检查级计数 |

所有数量同时记录快照编号、程序版本和生成日期。

## 8. 论文中的规范表述

推荐：

> 依据对应版本 NAICS 定义，研究纳入电力配电、其他发输配电、电力与通信线路施工，以及电气承包与布线安装四个互斥组，统称为电力及电气相关行业。其中线路施工组包含通信活动，电气安装组也不限于电网业务。

禁止：

> 本文数据覆盖四川电网全部企业。

> 所有样本均属于纯电力行业。

> OSHA 公开记录代表中国供电企业总体。
