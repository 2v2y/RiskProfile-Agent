
然后对比 FAISS+BGE（use_rag=true）与关键词回退（use_rag=false）的证据差异：

```bash
python - <<'PY'
from experiments import common
from adapters.retrieval_adapter import Stage9RetrievalAdapter
cfg, data, stage_config = common.setup()
loaded = common.load_everything(data)
s = common.build_evaluation_set(loaded, split="validation", limit=1)[0]
card = s["card"]
for use_rag in (True, False):
    r = Stage9RetrievalAdapter(data, top_k=3, use_rag=use_rag).run(
        card.get("historical_standard_codes") or [],
        card.get("historical_risk_categories") or [],
        query_id=card["sample_id"])
    print("use_rag=", use_rag, "items=", len(r.items))
    for it in r.items:
        print("  ", it.standard_number, it.section, it.evidence_id, round(it.score, 4), it.text[:80])
PY
```

要求：top-3 证据与本标准相关、标准编号经 canonical 统一、无覆盖时不伪造。
回报：3 个样本的 RAG vs keyword 证据对照 + 结论。
