## 检查清单（每次运行后）

- [ ] `check_stage9` 全绿（SKIP/WARN 需说明）
- [ ] `check_qwen` 通过
- [ ] `run_smoke` 的 `total_qwen_calls_ok > 0` 且与样本数匹配
- [ ] 无 `template_fallback`（若有：哪个方法/样本、Qwen 报什么错）
- [ ] 结果目录里有 `llm_calls.jsonl` + `llm_summary.json`
- [ ] 已把运行目录、commit、config、数据 SHA 写进本项目记录表

## 参考：qwen_ok 预期值（smoke --n 3，3 个样本）

- B0：0（固定模板，不用 LLM，属设计）
- B1/B3：3（每个样本都调一次 review LLM）
- B2/B4：有证据样本数（无证据样本按设计不调 LLM）
- B5：2 × 有证据样本数（review + 独立语义审查各一次）

若实际值远小于预期，先查 `llm_summary.json` 与 `llm_calls.jsonl`，不要继续降 max_tokens。
