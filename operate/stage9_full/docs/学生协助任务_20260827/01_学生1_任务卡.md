然后抽查 validation 样本，核对画像卡、事实、白名单与你的口径是否一致：

```bash
python - <<'PY'
from experiments import common
from src.agents.profile_agent import ProfileAgent
cfg, data, stage_config = common.setup()
loaded = common.load_everything(data)
for s in common.build_evaluation_set(loaded, split="validation", limit=5):
    card = s["card"]
    facts = ProfileAgent(whitelist_path=stage_config["paths"]["whitelist"], strict=True).run(card)
    print(card["sample_id"], card["quarter"], "n_facts=", facts["n_facts"])
    print("  codes:", (card.get("historical_standard_codes") or [])[:10])
    print("  risks:", card.get("historical_risk_categories"))
    print("  risk_score:", card.get("risk_score"), "percentile:", card.get("risk_percentile"))
PY
```

重点核对：

1. `historical_standard_codes` 空值率（当前 1809/5337 ≈ 33.9%，来自安全锁残留）是否符合预期；
2. `historical_risk_categories` / `risk_category_counts` 与 R1–R9 映射口径一致（含 R6=179）；
3. `risk_score` / `risk_percentile` / `model_version` / `score_evidence` 取值与你的交付一致；
4. `profile_version = FREEZE_20260814_001`；
5. 白名单 `whitelisted_fields` 是否覆盖画像卡全部字段。

回报：抽查 5 个样本的对照表 + 发现的问题（字段/口径/缺失）。
