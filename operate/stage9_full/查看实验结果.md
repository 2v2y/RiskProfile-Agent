# 阶段九跑完后：看哪些数据、怎么看

本文说明 `stage9_full` 各实验跑完后会产出哪些文件，以及用什么命令查看它们。
所有命令都从 `stage9_full/` 目录执行，用 `python` 即可（服务器环境自带），CSV 也可以直接用 Excel / WPS 打开。

## 0. 结果目录长什么样

每次运行都会在 `results/` 下生成一个**唯一的、不会覆盖的**目录，例如：

```text
results/
├── 20260824_232424_smoke_test_e1d10a/        # smoke test
├── comparison/20260824_232457_comparison_62fb7d/
│   ├── B0/outputs.jsonl … B5/outputs.jsonl   # 每方法逐样本完整输出
│   ├── rows.jsonl                            # 逐样本 x 方法 的指标
│   ├── summary.json                          # 每方法指标均值 + 判定分布
│   └── summary.csv                           # 上面的 CSV 版
├── ablation/…/ablation_summary.csv           # 消融：指标差值 + 95% CI
├── error_analysis/…/
│   ├── error_analysis.csv                    # 方法 + 样本ID + 错误类型
│   └── error_analysis_summary.json           # 每方法每错误类型计数/率
└── 20260824_…_stage9_b5_xxx/                 # B5 每个样本的完整运行目录
    ├── review_card.json  audit.json  semantic_audit.json
    ├── retrieval.json  profile_facts.json  state_trace.json
    ├── run_log.jsonl  output_manifest.json
```

用一句话找“最新一次”某类结果：

```bash
ls -dt results/comparison/*/ | head -1   # 最新一次对比实验
ls -dt results/*stage9_b5*/ | head -1    # 最新一个 B5 完整运行目录
```

## 1. 对比实验（最重要：六个方法谁更好）

### 看总表（每方法各指标均值 + PASS/DEFER/REJECT 分布）

```bash
# 终端里快速看
python -c "import json,glob,os; d=sorted(glob.glob('results/comparison/*/summary.json'), key=os.path.getmtime)[-1]; print(json.dumps(json.load(open(d,encoding='utf-8')), ensure_ascii=False, indent=2))"
```

或者直接打开该次运行目录里的 `summary.csv`（用 Excel/WPS）。

指标含义：

| 指标 | 越高越好 | 说明 |
|---|---|---|
| numeric_accuracy | 是 | 画像数字与 gold 一致的比例 |
| citation_validity | 是 | 引用是否真实存在于检索结果 |
| citation_correctness | 是 | 引用标准是否命中 gold 标准 |
| evidence_support | 是 | 有依据的陈述占比 |
| unsupported_claim | 否 | 无依据陈述占比 |
| traceability | 是 | 证据引用能否回溯到画像事实/检索证据 |
| safe_refusal | 是 | 安全拒绝/通过与 gold 对齐 |

`final_verdict_distribution` 是各方法的 PASS / DEFER(转人工) / REJECT(拒绝) 数量。

### 看某一方法逐样本指标

```bash
python -c "import json; [print(json.dumps(r, ensure_ascii=False)) for r in map(json.loads, open('results/comparison/<本次目录>/rows.jsonl', encoding='utf-8')) if r['method']=='B5']"
```

## 2. 消融实验（去掉某模块后指标掉多少）

打开 `results/ablation/<本次目录>/ablation_summary.csv`，列含义：

```text
comparison   = 哪两个配置在比（如 B5 vs full_minus_semantic_audit）
metric       = 哪个指标
full_mean    = 完整系统均值
variant_mean = 去掉模块后的均值
diff         = full - variant（正数=去掉后变差）
ci_lower/ci_upper = 95% Bootstrap 置信区间
n_pairs      = 配对样本数
```

判断：`diff` 的 95% 区间**不跨 0**，才说明该模块的贡献在统计上显著。

## 3. 错误分析（哪些样本、错在哪）

打开 `results/error_analysis/<本次目录>/error_analysis.csv`：

```text
method, sample_id, errors
B5,     bd9c…,      CITATION_ERROR;UNSUPPORTED_CLAIM
```

错误类型见 `evaluation/error_analysis.py` 的 `ERROR_TYPES`（NUMERIC_ERROR / CITATION_ERROR / EVIDENCE_UNSUPPORTED / UNSUPPORTED_CLAIM / OUT_OF_SCOPE / REFUSAL_ERROR）。

终端按方法统计错误率：

```bash
python -c "import json,glob,os; d=sorted(glob.glob('results/error_analysis/*/error_analysis_summary.json'), key=os.path.getmtime)[-1]; print(json.dumps(json.load(open(d,encoding='utf-8'))['rates'], ensure_ascii=False, indent=2))"
```

## 4. 定位某个错误样本，回看它完整走了一遍什么

1. 从 `error_analysis.csv` 拿到 `method + sample_id`；
2. 在 `<method>/outputs.jsonl` 里找这个样本的完整输出：

```bash
python -c "import json; sid='bd9c105e9b107348fc1b'; [print(json.dumps(r,ensure_ascii=False,indent=2)) for r in map(json.loads,open('results/comparison/<本次目录>/B5/outputs.jsonl',encoding='utf-8')) if r.get('sample_id')==sid]"
```

3. 若该样本是 B5 跑的，还能看它单独的完整运行目录（`results/*stage9_b5*/`），重点看：
   - `review_card.json`：最终建议卡（frozen_risk、profile_facts、review_points、evidence_ledger、final_verdict）
   - `audit.json`：确定性审查逐条 PASS/DEFER/REJECT
   - `semantic_audit.json`：独立语义审查逐条结论
   - `retrieval.json`：实际检索到的法规证据（evidence_id/document_id/standard/section/score）
   - `state_trace.json`：每一步的模块、耗时、状态变化

```bash
ls -dt results/*stage9_b5*/ | head -1 | xargs -I{} sh -c 'echo {}; python -m json.tool {}/review_card.json | head -80'
```

## 5. 对照 Ground Truth（看某个样本“标准答案”是什么）

gold 在 `benchmark_gold_restricted.jsonl`（受限，仅评价用）。按 sample_id 查：

```bash
python -c "import json; sid='bd9c105e9b107348fc1b'; [print(json.dumps(r,ensure_ascii=False,indent=2)) for r in map(json.loads,open('<RP_DATA_ROOT>/benchmark_gold_restricted.jsonl',encoding='utf-8')) if r.get('sample_id')==sid]"
```

gold 里要看：

- `expected_profile_facts_subset`：该样本画像数字的标准答案
- `gold_regulation_document_ids`：正确法规引用（含 `evidence_available`，false=知识库无片段，应单独统计）
- `expected_safe_defer_or_pass`：期望“安全转人工/通过”（true=证据不足应 DEFER；None=证据充分）

## 6. Smoke Test（先确认跑得通）

`results/<时间戳>_smoke_test_*/` 下：

- `validation_report.json`：画像契约校验结果（`passed/total` 应为 5337/5337）
- `outputs.json`：各方法对 1—3 个样本的完整输出

```bash
python -c "import json,glob,os; d=sorted(glob.glob('results/*smoke_test*/validation_report.json'), key=os.path.getmtime)[-1]; print(json.dumps(json.load(open(d,encoding='utf-8')),ensure_ascii=False,indent=2))"
```

## 7. 可追溯性：每个数字用哪版代码/数据/配置

每个运行目录里的 `config.json` 是本次实验用的完整配置（含数据路径）；B5 目录里的 `output_manifest.json` 是各输出文件的 SHA-256。要回答“这个数字怎么来的”，就查对应运行目录的 `config.json` + Git commit + 数据文件 SHA。

```bash
git -C .. log --oneline -3                    # 代码版本
python -m json.tool <本次目录>/config.json      # 本次配置
```

## 8. 一句话速查表

| 想知道的 | 看哪个文件 | 命令 |
|---|---|---|
| 六方法谁更好 | comparison/summary.csv | Excel 打开 |
| 某模块有没有用 | ablation/ablation_summary.csv | Excel 打开 |
| 哪些样本错、错哪类 | error_analysis/error_analysis.csv | Excel 打开 |
| 某样本完整链路 | comparison/`<方法>`/outputs.jsonl 或 B5 运行目录 | 见第 4 节 |
| 某样本标准答案 | benchmark_gold_restricted.jsonl | 见第 5 节 |
| 跑得通没有 | smoke_test/validation_report.json | 见第 6 节 |
