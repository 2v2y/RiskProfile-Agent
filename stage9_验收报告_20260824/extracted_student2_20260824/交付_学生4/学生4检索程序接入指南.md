## 检索系统是什么

学生2构建的是**混合检索系统**，方法叫"Filter-then-Rank"（先过滤再排序）：

| 查询类型 | 示例 | 处理方式 |
|---------|------|---------|
| 标准编号 | `1910.132` | 先精确过滤出所有1910.132的片段，再用BGE语义排序 |
| DOL格式 | `19100132 Q01` | 自动转换成`1910.132`，再按标准编号处理 |
| 自然语言 | `fall protection` | 纯BGE语义检索（FAISS全局搜索） |

验证结果：Recall@3=1.0000，MRR=1.0000（93条验证集全部命中，正确答案总排第1位）。

### 第3步：调用检索接口

```python
import sys
sys.path.append('src/retrieval')
from rag_retriever import RAGRetriever

# 初始化（首次约30秒，会加载BGE模型和FAISS索引）
retriever = RAGRetriever()

# === 三种调用方式 ===

# 方式1：标准编号查询
results = retriever.search("1910.132", k=3)

# 方式2：DOL格式查询（违章记录里的原始格式，自动转换）
results = retriever.search("19100132 Q01", k=3)

# 方式3：自然语言查询
results = retriever.search("fall protection equipment", k=3)

# === 处理结果 ===
for r in results:
    print(f"得分={r['score']:.4f} | {r['standard']} {r['section']}")
    print(f"  {r['text'][:200]}")
```

## 关键参数

| 参数 | 值 | 说明 |
|------|---|------|
| 返回条数k | **3** | 已验证的最佳值，Recall@3=100% |
| 检索方法 | 混合检索(Filter-then-Rank) | 标准编号→精确过滤+BGE排序；自然语言→纯BGE |
| BGE模型 | BAAI/bge-small-en-v1.5 | 384维向量，首次运行自动下载（约200MB） |
| FAISS索引 | IndexFlatIP | 内积索引（L2归一化后等价于余弦相似度） |

## 常见问题

### Q1: 首次运行很慢？
首次运行会从HuggingFace下载BGE模型（约200MB），之后从本地缓存加载。初始化加载FAISS索引+BGE模型约需30秒。

### Q2: standard字段格式不一致？
违章记录里是`19100132 Q01`（DOL格式），知识库里是`1910.132`（标准格式）。检索器内部会自动转换，你不需要处理。

### Q3: 有些标准编号查不到？
如果精确匹配为空，检索器会自动用前缀匹配。比如查`1926.105`会匹配到`1926.1050`、`1926.1051`等。如果前缀匹配也为空，会回退到纯BGE语义检索。

### Q4: 怎么测试检索是否正常？
用`retrieval_gold.csv`里的93条验证数据测试：
```python
import csv
retriever = RAGRetriever()
with open("knowledge/retrieval_gold.csv", encoding="gbk") as f:
    for row in csv.DictReader(f):
        results = retriever.search(row["查询"], k=3)
        top1 = results[0]
        match = row["正确标准编号"] in top1["standard"] or top1["standard"].startswith(row["正确标准编号"])
        print(f"{row['查询']} → {top1['standard']} {'✓' if match else '✗'}")
```

### Q5: 能不能改返回条数？
可以，把`k=3`改成`k=5`或`k=10`。但k=3已验证是最佳值（Recall=100%，Precision最高）。

## 检索流程图（供理解）

```
用户输入查询（标准编号 / DOL格式 / 自然语言）
    │
    ▼
判断查询类型
    │
    ├── 是标准编号? ──→ 格式转换（DOL→标准）
    │                      │
    │                      ▼
    │                 精确过滤（standard字段匹配）
    │                      │
    │                 有匹配? ──→ BGE在匹配中排序
    │                      │
    │                 无匹配 → 前缀匹配
    │                      │
    │                 有匹配? ──→ BGE排序
    │
    └── 自然语言 ──→ 纯BGE语义检索（FAISS全局搜索）
                                   │
                                   ▼
                            返回Top-3结果
                            （片段编号 + 法规正文 + 得分）
```
